# GTP Reader

GTP Reader is a Chrome extension that summarizes the main article content on any webpage using GPT.  
It’s designed for instant use — no API keys or setup needed once installed.

---

## 🚀 Features
- One-click article summarization
- Clean, distraction-free reader panel
- Works automatically after install — no manual API key required
- Secure: all requests routed through a privacy-friendly proxy

---

## 🧰 Developer Quickstart

Clone the repo and load the extension locally:

```bash
git clone https://github.com/jamesschaffer/gtp-reader.git
cd gtp-reader

	1.	Open chrome://extensions
	2.	Enable Developer mode
	3.	Click Load unpacked → select this folder
	4.	The extension should now appear in your toolbar.
